## 2. Diary

### Diary creation and saved locations

* Create a diary entry from the Diary tab
* Select an existing saved map location for the new entry
* Show the saved entry immediately in diary lists and on its map marker

### Tag search

* Select a tag on a diary detail screen to open tag search with that tag prefilled
* Show diary entries that use the selected tag
* Edit the tags of an existing diary entry

### 다이어리

* 다이어리 작성
* 다이어리 조회
* 목록 및 지도 마커에서 다이어리 상세 조회
* 다이어리 수정
* 상세 화면에서 제목, 내용, 여러 장의 사진, 태그 수정
* 카메라 촬영 또는 사진 보관함에서 일기 사진 등록
* 다이어리 삭제

### Handwriting editor

* 한 다이어리에 최대 10개의 세로·가로 3:4 필기 페이지 작성
* iPad/PencilKit과 Android 태블릿/Jetpack Ink에서 다시 편집할 수 있는 schema v2 공통 문서 포맷
* 펜, 형광펜, 지우개 및 실행 취소/다시 실행
* 페이지 생성, 삭제, 복제, 회전 및 드래그 순서 변경
* 무지, 줄 노트, 격자, 도트, 크림색 및 사용자 이미지 배경
* 갤러리와 다이어리 사진을 편집 레이어로 추가
* 기본 스티커와 이미지의 직접 이동, 핀치 확대·축소, 회전, 잠금, 숨김 및 순서 변경
* 올가미로 여러 필기 획을 선택해 페이지 경계 안에서 한 번에 이동하고 한 단계로 실행 취소
* 원본 이미지 보존, EXIF 정규화 및 긴 변 4096px 편집 미리보기
* 직렬 자동 저장, background flush, 실패 재시도, 앱 재실행 복원 및 revision-safe PNG 미리보기
* 캔버스 중심 레이아웃, 간결한 플로팅 툴바, 태블릿 우측 패널 및 내부 휴대폰 바텀시트 UI
* 전체 문서 최대 1,000획·250,000점, 획당 20,000점, 페이지당 30개·문서당 150개 편집 레이어 제한
* 이미지 원본당 40MB·문서 원본 합계 250MB 제한과 증분 native-to-JS ink 변경 전송
* 확대·회전된 viewport에서도 일치하는 사진/스티커 제스처와 pointer-type 기반 손가락 이동
* PencilKit 실제 획 왕복 및 Jetpack Ink Android instrumentation 계약 검증
* 이번 제품 진입점은 태블릿에만 노출
