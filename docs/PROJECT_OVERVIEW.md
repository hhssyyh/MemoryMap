# PROJECT_OVERVIEW

프로젝트명: Memory Map

---

# 프로젝트 개요

사용자가 방문한 장소에서 촬영한 사진을 기반으로 자동으로 위치를 기록하고, 해당 위치에 다이어리를 작성할 수 있는 모바일 애플리케이션.

사진과 장소를 지도 위에 시각적으로 관리할 수 있으며 장소별, 날짜별로 다이어리 작성이 가능하다.

Android / iOS를 동시에 지원하는 크로스 플랫폼으로 개발한다.

---

# 프로젝트 목표

- 사진 기반 위치 기록 자동화
- 지도 중심의 다이어리 관리
- 여행 및 일상 기록 서비스 제공
- AI 기반 개인 맞춤 추천 제공

---

# 주요 기능

## 1. 회원 관리

- 회원가입
- 로그인
- 로그아웃
- 프로필 관리

---

## 2. 사진 기반 위치 기록

- 사진 촬영
- 갤러리 사진 업로드
- GPS 정보 자동 저장
- 지도에 마커 생성

---

## 3. 다이어리 작성

- 제목
- 내용
- 사진 첨부
- 방문 날짜
- 태그

---

## 4. 지도 기능

- 방문 장소 표시
- 마커 선택 시 다이어리 조회
- 지역별 탐색
- 확대 / 축소

---
