# Tech Stack

## Mobile

- React Native
- Expo
- TypeScript

### 선정 이유

- Android / iOS 동시 지원
- 코드 재사용률 향상
- React 생태계 활용

---

## Map

- Mapbox

### 선정 이유

- 모바일 지도 UI 및 마커 표시 지원
- 지도 스타일 커스터마이징 가능
- 위치 기반 다이어리 기능 확장에 적합

---

## Backend

- Spring Boot

### 선정 이유

- REST API 제공
- Spring Security 연동
- 확장성 및 유지보수성

---

## Database

- 안정적인 트랜잭션 지원
