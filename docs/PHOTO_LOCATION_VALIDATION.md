# 사진 위치 지도 검증 체크리스트

## 목적

사진 위치 지도 기능은 기기 사진 보관함, OS 권한, EXIF/GPS 메타데이터,
SQLite 캐시, 지도 UI가 함께 동작해야 한다. 자동 테스트만으로는 실제
사진첩 권한과 메타데이터 동작을 완전히 검증할 수 없으므로, 코드 검증과
실기기 검증을 분리한다.

## 자동 검증

로컬에서 아래 명령을 통과해야 한다.

```sh
cd app
npm run typecheck
npm test -- --runInBand
npx expo config --type public
```

확인 기준:

- `expo-media-library`가 `package.json`에 포함되어 있다.
- `app.json`에 `expo-media-library` 플러그인이 포함되어 있다.
- iOS `Info.plist`에 사진 보관함 권한 문구가 들어 있다.
- Android `AndroidManifest.xml`에 이미지 읽기 권한이 들어 있다.
- 사진 위치 마커 변환 테스트가 통과한다.

## iOS 실기기 검증

시뮬레이터보다 실제 iPhone에서 확인하는 것이 우선이다. iCloud 사진,
제한된 사진 접근, 실제 카메라 EXIF 동작은 시뮬레이터와 다를 수 있다.

확인할 사진:

- 기본 카메라 앱으로 촬영한 위치 정보 있는 사진
- 위치 서비스가 꺼진 상태에서 촬영한 사진
- 스크린샷
- Safari 또는 메신저에서 저장한 다운로드/공유 이미지
- 편집 또는 압축 앱을 거친 이미지

확인할 권한 상태:

- 전체 사진 접근 허용
- 선택한 사진만 허용
- 사진 접근 거부
- 설정 앱에서 권한을 변경한 뒤 앱 재진입

기대 동작:

- 앱 첫 진입 시 사진 권한이 없으면 권한 요청이 나온다.
- 전체 접근 허용 시 GPS가 있는 카메라 사진만 지도 사진 마커로 표시된다.
- 선택 접근 허용 시 선택된 사진 중 GPS가 있는 사진만 표시된다.
- 권한 거부 시 기존 다이어리 마커는 계속 표시되고 사진 마커는 표시되지 않는다.
- 스크린샷/다운로드/공유 이미지에 GPS가 없으면 자동 마커가 생기지 않는다.
- 다이어리에 첨부된 사진은 사진 원본 위치가 아니라 다이어리 위치에 표시된다.

## Android 실기기 검증

Android는 OS 버전에 따라 사진 권한이 다르므로 최소 두 범주를 확인한다.

- Android 13 이상: `READ_MEDIA_IMAGES`
- Android 14 이상: 제한된 사진 접근 `READ_MEDIA_VISUAL_USER_SELECTED`

확인할 사진:

- 기본 카메라 앱으로 촬영한 위치 정보 있는 사진
- 위치 태그 저장이 꺼진 상태에서 촬영한 사진
- 스크린샷
- 다운로드 폴더 이미지
- 메신저 또는 공유 앱에서 저장한 이미지

확인할 권한 상태:

- 모든 사진 허용
- 선택한 사진만 허용
- 사진 접근 거부
- 설정 앱에서 권한을 변경한 뒤 앱 재진입

기대 동작:

- 앱 첫 진입 시 사진 권한이 없으면 권한 요청이 나온다.
- GPS가 있는 카메라 사진만 자동 사진 마커로 표시된다.
- GPS가 없는 사진은 자동 마커에서 제외된다.
- 권한 변경 후 앱이 active 상태가 되면 동기화가 다시 시도된다.
- 대량 사진첩에서도 앱 첫 렌더링이 막히지 않고 배치 단위로 마커가 늘어난다.

## 대용량 사진첩 검증

최소 1,000장 이상의 사진이 있는 기기에서 확인한다.

확인 기준:

- 앱 첫 화면이 권한 요청 이후에도 장시간 멈추지 않는다.
- 지도 이동/확대/축소가 동기화 중에도 가능하다.
- 사진 마커가 한 번에 모두 뜨지 않아도 배치 단위로 점진적으로 반영된다.
- 앱을 종료했다 다시 열면 이전 캐시를 활용하고 이어서 동기화한다.

## 완료 기준

이 기능의 개발 완료 기준은 다음과 같다.

- 자동 검증 명령이 모두 통과한다.
- iOS 실기기에서 권한, 사진 종류, GPS 유무 케이스가 확인된다.
- Android 실기기에서 권한, 사진 종류, GPS 유무 케이스가 확인된다.
- 대량 사진첩에서 앱 시작과 지도 조작이 막히지 않는다.
